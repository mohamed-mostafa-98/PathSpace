بدء الاستخدام

التثبيت والتشغيل

01

المثبت

نزّل MSI وتحقق من SHA-256، ثم افتحه واتبع Windows Installer. تتضمن الحزمة .NET 8 وتضيف PathSpace إلى قائمة ابدأ.

02

المحمول

نزّل ZIP وتحقق منه، ثم فك المجلد كاملًا وشغّل PathSpace.App.exe. ثبّت .NET 8 Desktop Runtime إذا طلبه Windows.

معاينة خاصة: الحزم غير موقعة حاليًا. تحقق من SHA-256 وتوقع احتمال ظهور SmartScreen.

سطر الأوامر

محرك JSONL

تتضمن الحزمة المحمولة محرك القراءة فقط نفسه:

powershell -NoProfile -ExecutionPolicy Bypass -File .\cli\pathspace.ps1 `
  scan --path "D:\Projects"

استخدم --large-file-threshold-bytes لتغيير حد الملفات الكبيرة و--output للحفظ محليًا. اضغط Ctrl+C للإلغاء الآمن.

مسارات محلية فقط: تُرفض المسارات البعيدة ولا تُتبع نقاط إعادة التحليل خارج الهدف.

حل المشكلات

أسئلة شائعة

يقول Windows «ناشر غير معروف».

الإصدار غير موقع. تحقق من SHA-256 قبل التشغيل.

التطبيق المحمول يطلب .NET.

ثبّت Microsoft .NET 8 Desktop Runtime لنظام Windows x64 أو استخدم MSI.

تظهر تحذيرات لبعض المجلدات.

رفض الوصول واختفاء الملفات متوقعان أثناء الفحص؛ يتابع PathSpace بأمان.

لماذا زر التنفيذ معطل؟

أنشئ المعاينة وافحص الأهداف ثم حدد التأكيد الصريح.

هل الإلغاء يحذف شيئًا؟

لا. يعيد نتائج جزئية للقراءة فقط ويبقي التنظيف معطلًا.
