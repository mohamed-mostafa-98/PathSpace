# PathSpace 0.1.0-private

PathSpace 0.1.0-private is an unsigned preview for Windows 10/11 x64. It is published for evaluation while production publisher signing, Windows 10 sign-off, and signed clean-host installer lifecycle validation remain open.

## Downloads

- `PathSpace-0.1.0-win-x64.msi` — self-contained installer with the .NET 8 Desktop Runtime.
- `PathSpace-0.1.0-private-portable-win-x64.zip` — framework-dependent portable package requiring the .NET 8 Desktop Runtime.
- `SHA256SUMS-release.txt` — SHA-256 digests for both downloads.

## Highlights

- Local fixed-drive, removable-drive, and individual-folder analysis.
- Categorized usage, large-file results, warnings, filters, and local JSON/CSV export.
- Guided Docker, WSL, Notion, Claude, pagefile, hibernation, and volume-optimization diagnostics.
- Read-only defaults, exact previews, explicit confirmation, allow-listed actions, and post-action verification.
- Fully offline operation with no telemetry.
- Responsive WPF interface with progress, cancellation, keyboard workflows, accessible names, live regions, and completed Windows 11 manual accessibility sign-off.

## Verification

- 12 contract/schema, 6 worker-security, 17 application/accessibility, and 23 PowerShell engine/signing tests.
- Packaged GUI complete, cancellation, keyboard-only, screen-reader-semantics, and UAC-cancellation workflows.
- Checksummed portable and MSI artifacts, packaged worker smoke test, MSI structural/extraction validation, and disposable full-package signing validation.
- Windows 11 local-folder, fixed-drive, removable-drive, unsigned MSI lifecycle, and offline behavior evidence.

## Known release gates

- The preview is not publisher-signed; Windows may show Unknown Publisher or SmartScreen warnings.
- Windows 10 compatibility sign-off remains open.
- Production Authenticode certificate/timestamp configuration and signed install/upgrade/uninstall validation remain open.

## Safety

Verify `SHA256SUMS-release.txt` before running a download. Cleanup actions are never preselected. Review every preview and risk label before confirming an action.
